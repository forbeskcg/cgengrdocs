# Robot Software

## Getting Started

* [wpilib docs](https://docs.wpilib.org/en/stable/): WPILib is the software framework used for FRC robots. This is the definitive source for all WPILib info, including hardware components, software in multiple languages, and both beginner and advanced features.
* [frcsoftware.org](https://frcsoftware.org/): A new (as of fall 2026) resource to learn the fundamentals of FRC software
* REPL tools
    * [JDoodle](https://www.jdoodle.com/)
    * [OneCompiler](https://onecompiler.com/)
* [typing.io](https://typing.io/): Typing practice using real codebases
* [Codewars](https://www.codewars.com/): Small programming challenges to improve your skills
* [Learn Git Branching](https://learngitbranching.js.org/?locale=en_US): An interactive tool for learning Git essentials
